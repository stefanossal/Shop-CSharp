# Shop-CSharp 🏬

A Windows desktop application simulating a multi-area shop environment where users can navigate between different functional spaces such as photocopy center, cafeteria, library, and online ordering system.

---

## 🧭 Overview

The application starts from a **main menu (home screen)** where the user can choose between different areas of the shop by clicking on interactive icons.

Each area provides a different set of functionalities, simulating a real-world shopping and service environment.

---

## 🏠 Main Screen

From the home screen, the user can navigate to:

- 📄 Photocopy / Scanner / Printer Area  
- ☕ Cafeteria  
- 📚 Library  
- 🛗 Elevator System  
- 🛒 Electronic Ordering System  

---

## 🖨️ Photocopy / Scanner / Printer Area

In this section, the user can:

- Photocopy documents  
- Scan files  
- Print documents  

---

## ☕ Cafeteria

The cafeteria allows the user to:

- Sit and browse the menu  
- Place an order  
- Pay for the order  
- Return to the main screen after completion  

---

## 📚 Library

- Simple library viewing area  
- Users can explore the environment  

---

## 🛒 Electronic Ordering System

In this section, the user can:

- Search for books  
- Add items to shopping cart  
- Complete purchase  

---

## 🛗 Elevator System

The elevator allows navigation between floors/areas:

- Photocopy / Scanner area  
- Library  
- Cafeteria
